# Portfolio

A static portfolio site built with plain HTML, CSS, and JavaScript.

## Structure

```
portfolio/
├── index.html   # Main page
├── style.css    # All styles
└── script.js    # Scroll reveal + nav shadow
```

## Sections

1. **Work / Case Study** – Featured card + 3 project cards
2. **Writing** – 2 articles + 2 research publications
3. **Side Projects** – 3 interactive pages
4. **Footer** – Contact

## Design tokens

| Token | Value |
